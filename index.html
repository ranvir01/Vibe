Rules this app follows
  • Missing: a cell is missing when it is blank or equals NA, N/A, NaN, null, None or #N/A (any letter case). 0 and - are not missing.
  • Numeric: a column is numeric when every non-missing value is a plain number such as 42, -1.5, .5 or 1e2. Values like 1,234, $5 or 5% make the column text.
  • Statistics use only the non-missing numeric values. Missing values are skipped, never counted as zero.
  • Sample SD divides by n − 1 (Excel STDEV.S, pandas .std()). Population SD divides by n (Excel STDEV.P, numpy.std()).
  • CSV quoting follows RFC 4180: quoted values may contain commas, line breaks and doubled quotes. Comma, semicolon and tab delimiters are detected from the header row.
